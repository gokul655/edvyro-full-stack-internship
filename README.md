# EdVyro Full Stack Development - Internship Explorer

## Project Overview

This project is a beginner-friendly Internship Explorer developed as part of the EdVyro Full Stack Development Virtual Internship.

The website allows users to search and filter internship opportunities by domain.

## Features

- Responsive web design
- Semantic HTML structure
- Internship search
- Domain filtering
- Clear filters option
- Empty-result state
- Error state
- Keyboard-friendly interactions
- Accessible form labels
- Responsive layout for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
